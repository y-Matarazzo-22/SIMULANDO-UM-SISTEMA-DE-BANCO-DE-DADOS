# PROJETO-SIMULANDO-UM-SISTEMA-DE-BANCO-DE-DADOS
OBJETIVO: Vivenciar, de forma prática e acessível, como os dados são transformados em informação e conhecimento, e como um sistema de banco de dados ajuda a garantir organização, consistência, segurança e controle sobre essas informações.

CONTEXTO: Imagine  que  você  trabalha  em  uma  empresa  fictícia  chamada EducaTech, responsável por organizar e analisar dados de estudantes de cursos livres. A empresa deseja melhorar seus processos e entender melhor o perfil de seus alunos para criar novas estratégias de atuação. Você foi convidado(a) para simular como um sistema de banco de dados pode transformar dados  brutos em informações  organizada se,  a  partir  delas,  gerar conhecimento útil para decisões.
